# DSWD AICS Online Assistance Portal — Demo Prototype

This repository contains a **front-end demonstration only** based on the HTML screens generated by Google Stitch.

## Pages
- `index.html` — Client dashboard (Stitch screen)
- `apply.html` — Apply for assistance (Stitch screen)
- `upload-requirements.html` — Upload requirements (Stitch screen)
- `verification.html` — Document verification (Stitch screen)
- `assessment-schedule.html` — Demo appointment scheduling page
- `application-status.html` — Demo application timeline
- `notifications.html` — Sample notifications
- `feedback.html` — Demo feedback form

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders from this project to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for deployment and open the Pages URL shown in Settings.

The main entry page is `index.html`.

## Important limitations
- This is not an official DSWD service and is not connected to DSWD systems.
- Application and feedback data use browser `localStorage`, so data stays in that browser and is not shared with staff or other clients.
- Selecting files does not upload them to a server.
- SMS/email notifications, real eligibility checks, staff verification/approval, secure document storage, and real appointment availability are not implemented.
- The pages load Tailwind CSS, Google Fonts, and Material Symbols from external CDNs, so an internet connection is needed for the intended appearance.
- Use only fictional data. Do not enter or publish real applicant personal information or documents.
